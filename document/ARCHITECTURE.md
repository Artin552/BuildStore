## Жизненный цикл заказа

```
1. CART
   ├─ Пользователь добавляет товары
   ├─ Товары сохраняются в localStorage
   └─ Badge обновляет счетчик

2. REVIEW
   ├─ Пользователь открывает cart.html
   ├─ Видит все товары и сумму
   └─ Может изменить количество

3. CHECKOUT
   ├─ Нажимает "Оформить заказ"
   ├─ Проверяется авторизация
   ├─ Отправляется POST /api/orders
   └─ Backend создает заказ и items

4. DATABASE
   ├─ Запись в таблицу orders (статус: pending)
   ├─ Записи в таблицу order_items
   └─ Цены зафиксированы (price_at_purchase)

5. SUCCESS
   ├─ Корзина очищается (localStorage)
   ├─ Показывается номер заказа
   └─ Ссылка на "Мои заказы"

6. HISTORY
   ├─ orders.html загружает заказы
   ├─ GET /api/orders возвращает список
   ├─ Отображаются с статусом и товарами
   └─ Можно просмотреть детали
```

## Статус заказа

```
pending → confirmed → shipped → delivered
   ↓                               
cancelled (в любой момент)

pending:     ⏳ Ожидание подтверждения
confirmed:   ✅ Подтверждено
shipped:     🚚 Отправлено
delivered:   📦 Доставлено
cancelled:   ❌ Отменено
```

```
checkout() {
  const token = localStorage.getItem('token')
  if (!token) {
    window.location.href = '/frontend/auth.html'
  }
  // отправить заказ с token в Authorization header
}
```

## API Последовательность вызовов

```
1️⃣  GET /api/listings?id=1
    → Получить товар для добавления в корзину

2️⃣  Добавить товар в localStorage (cart.js)
    → window.cart.addItem(listing)

3️⃣  POST /api/orders
    Headers: Authorization: Bearer TOKEN
    Body: {items: [...], total: "1000"}
    → Создать заказ

4️⃣  GET /api/orders
    Headers: Authorization: Bearer TOKEN
    → Получить список заказов

5️⃣  GET /api/orders/:id
    Headers: Authorization: Bearer TOKEN
    → Получить детали заказа

6️⃣  PATCH /api/orders/:id
    Headers: Authorization: Bearer TOKEN
    Body: {status: "shipped"}
    → Обновить статус (для админа)
```

## Сценарий использования

```
Пользователь:
  1. Регистрируется/Входит
  2. Просматривает товары (listings.html)
  3. Кликает на товар (product.html?id=X)
  4. Нажимает "Добавить в корзину"
  5. Товар добавляется в localStorage
  6. Badge показывает количество
  7. Нажимает значок корзины (🛒)
  8. Переходит на cart.html
  9. Видит все товары в корзине
  10. Может изменить количество
  11. Нажимает "Оформить заказ"
  12. Требует авторизация (проверка token)
  13. Создается заказ в БД
  14. Показывается номер заказа
  15. Может перейти на orders.html
  16. Видит историю всех заказов
  17. Может просмотреть детали
```
