## 🎯 Основные возможности

### 🛒 Корзина (Frontend)
- Добавление товаров в корзину
- Удаление товаров из корзины
- Изменение количества товаров
- Расчет общей стоимости в реальном времени
- Сохранение в localStorage (между сеансами)
- Badge со счетчиком товаров в хедере

### 📄 Страницы
- **cart.html** - полный интерфейс корзины
- **orders.html** - история всех заказов пользователя
- Интегрирована в dashboard.html кнопка "Мои заказы"

### 💳 Оформление заказа
- Проверка авторизации (JWT)
- Отправка товаров на сервер
- Создание заказа в БД
- Сохранение цен на момент покупки
- Успешное сообщение с номером заказа
- Очистка корзины после оформления

### 📊 История заказов
- Список всех заказов пользователя
- Статусы: pending, confirmed, shipped, delivered, cancelled
- Цветовое выделение статусов
- Просмотр товаров в каждом заказе
- Просмотр деталей заказа

### 🔌 API (Backend)
```
POST   /api/orders          Создать заказ
GET    /api/orders          Получить заказы пользователя
GET    /api/orders/:id      Получить детали заказа
PATCH  /api/orders/:id      Обновить статус заказа
```

### 💾 Таблицы БД
- **orders** - информация о заказах
- **order_items** - товары в заказах
- С сохранением цен (price_at_purchase)

## 🚀 Как использовать

### 1. Запустить
```bash
cd backend
npm start
```

### 2. Открыть браузер
```
http://localhost:4000
```

### 3. Использовать
- **Добавить в корзину**: Нажать кнопку на странице товара
- **Просмотреть корзину**: Нажать 🛒 в хедере
- **Оформить заказ**: Нажать "Оформить заказ" в корзине
- **История заказов**: Личный кабинет → "Мои заказы"

## 🎓 Примеры использования

### Frontend
```javascript
// Добавить товар
window.cart.addItem({id: 1, title: "Цемент", price: "500"})

// Получить все товары
const items = window.cart.getItems()

// Получить сумму
const total = window.cart.getTotal()
```

### API
```bash
# Создать заказ
curl -X POST http://localhost:4000/api/orders \
  -H "Authorization: Bearer TOKEN" \
  -d '{"items": [...], "total": "1000"}'

# Получить заказы
curl http://localhost:4000/api/orders \
  -H "Authorization: Bearer TOKEN"
```
