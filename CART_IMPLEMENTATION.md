# 🛒 Механика корзины и покупок - Реализация

## 📋 Описание

Реализована полнофункциональная система корзины и оформления заказов для маркетплейса BuildStoreNET.

## ✨ Основные функции

### Frontend (Фронтенд)
- ✅ **Корзина в localStorage** - сохраняется между сеансами
- ✅ **Быстрое добавление товаров** - кнопка на странице товара
- ✅ **Значок корзины в хедере** - показывает количество товаров
- ✅ **Страница корзины** - полный список с редактированием
- ✅ **Оформление заказа** - требует авторизации
- ✅ **История заказов** - страница "Мои заказы" в личном кабинете

### Backend (Бэкенд)
- ✅ **API для заказов** - создание и получение заказов
- ✅ **Таблицы БД** - orders и order_items
- ✅ **Сохранение цен** - фиксирует цену на момент покупки
- ✅ **Проверка авторизации** - все операции требуют JWT токена

## 🚀 Как использовать

### 1. Запуск сервера
```bash
cd backend
npm start
```
Сервер запустится на `http://localhost:4000`

### 2. Использование корзины

#### Добавление товара в корзину
- Перейти на страницу товара (product.html?id=X)
- Нажать кнопку "Добавить в корзину"
- Товар добавится в localStorage корзины
- Badge в хедере обновит количество

#### Просмотр корзины
- Перейти на страницу `/frontend/cart.html`
- Увидеть список товаров с ценами
- Изменить количество товаров
- Удалить товары из корзины

#### Оформление заказа
1. Нажать кнопку "Оформить заказ" в корзине
2. Если не авторизован - перенаправит на вход
3. Заказ создастся в БД
4. Корзина очистится
5. Показатся детали заказа с номером

#### Просмотр истории заказов
- В личном кабинете (dashboard.html) нажать "Мои заказы"
- Откроется страница `/frontend/orders.html`
- Видны все заказы пользователя
- Можно просмотреть детали каждого заказа

## 🗄️ Таблицы БД

### Таблица orders
```sql
CREATE TABLE orders (
  id INTEGER PRIMARY KEY,
  user_id INTEGER NOT NULL,
  total TEXT,
  status TEXT DEFAULT 'pending',
  created_at INTEGER,
  FOREIGN KEY (user_id) REFERENCES users(id)
)
```

### Таблица order_items
```sql
CREATE TABLE order_items (
  id INTEGER PRIMARY KEY,
  order_id INTEGER NOT NULL,
  listing_id INTEGER NOT NULL,
  quantity INTEGER DEFAULT 1,
  price_at_purchase TEXT,
  created_at INTEGER,
  FOREIGN KEY (order_id) REFERENCES orders(id),
  FOREIGN KEY (listing_id) REFERENCES listings(id)
)
```

## 🔌 API эндпоинты

### Создать заказ
```
POST /api/orders
Headers: Authorization: Bearer <token>
Body: {
  items: [{id, title, price, quantity}, ...],
  total: "1000.00"
}
Response: {id, user_id, total, status, created_at}
```

### Получить заказы пользователя
```
GET /api/orders?page=1&limit=10
Headers: Authorization: Bearer <token>
Response: [{...order с items}, ...]
```

### Получить заказ по ID
```
GET /api/orders/<id>
Headers: Authorization: Bearer <token>
Response: {id, user_id, total, status, items: [...], created_at}
```

### Обновить статус заказа
```
PATCH /api/orders/<id>
Headers: Authorization: Bearer <token>
Body: {status: "shipped"}
Response: {success: true, status: "shipped"}
```

## 📊 Статусы заказов

- `pending` - Ожидание подтверждения (новый заказ)
- `confirmed` - Подтвержден
- `shipped` - Отправлен
- `delivered` - Доставлен
- `cancelled` - Отменен

## ⚙️ Технические детали

### Корзина (Frontend)
- Хранится в `localStorage` под ключом `buildstore_cart`
- JSON массив объектов: `{id, title, price, imagePath, quantity}`
- Автоматически обновляется при добавлении/удалении товаров
- Badge в хедере обновляется в реальном времени

### Оформление заказа
1. Пользователь нажимает "Оформить заказ"
2. Проверяется наличие JWT токена в localStorage/sessionStorage
3. Формируется request с товарами из корзины
4. Backend создает запись в `orders` таблице
5. Для каждого товара создается запись в `order_items`
6. Frontend очищает корзину и показывает успех
